# ♡ Study Timer ♡

A cute scrapbook-themed timer for studying!

This was inspired by my struggles during junior year (ᵕ•᷄ ᴗ•᷅ )

## ✿ Features

- A study timer
- Create and choose different subjects
- Study leaderboard
- Track time spent studying today
- Track time spent studying this week
- Saves your study data using localStorage
- Cute pink scrapbook-inspired layouts
- Notebook-paper background
- Decorative stickers and bows

## ♡ How to Use

1. Download the project files.
2. Open `index.html` in your browser.
3. Select an existing subject or create a new one.
4. Click **Start** and begin studying!
5. Click **Pause** when you're finished or taking a break.
6. Your completed study session is automatically saved. ♡⸜(˶˃ ᵕ ˂˶)⸝♡
